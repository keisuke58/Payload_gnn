03 — Deep dive

The hydrogen-tank extension

The H3 LH2/LOX tanks are Al-Li welded structures at cryogenic temperature (LH2 −253 °C). The damage physics differ from the fairing, but the pipeline transfers with targeted additions.

Fig. 1 — Fairing (existing) vs. hydrogen tank (proposed)
Fairing — existingHydrogen tank — proposed
StructureCFRP / Al-honeycomb sandwichAl-Li welded tank (future: CFRP cryotank)
Primary defectsSkin–core debondingWeld flaws · thermal-cycle microcracks · insulation debond · H-embrittlement
LoadingThermal (CTE) + staticInternal pressure + cryogenic thermal stress + fill-cycle fatigue
Key physicsCurvature · laminate stackingCryogenic property shift · leak paths · permeability

Reuse as-is

  • GW + GNN — Lamb-wave propagation on tank walls
  • Domain adaptation — fairing→tank, ambient→cryogenic shift
  • Temperature-robustness framework — cryo is the extreme operating point
  • Conformal detection & UQ — go/no-go reliability guarantee

Build new

  • Al-Li cylinder FEM with pressure + cryo thermal stress
  • Weld-line & thermal-cycle crack defect models
  • Node features: cryogenic properties + pressure flag
  • Leak-path / permeability labeling for prognosis

FEM generation

Reuse build_graph.py / build_gw_graph.py; add cryogenic material properties and an internal-pressure flag to node features.

Training

Run existing train.py / train_gw.py unchanged — verify on one sample, then scale to the full batch.

sim2real + guarantee

Bridge ambient test data → cryogenic operation with the existing DA toolkit; wrap leak-risk decisions in split-conformal FPR guarantees.
